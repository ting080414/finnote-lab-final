## EPS Surprise 是什麼？

每股盈餘（Earnings Per Share, EPS）是企業獲利指標之一。投資人除了關心企業賺多少，也常關心企業公布的 EPS **是否超過分析師原先預期**。

一種常見定義為：

```text
EPS Surprise = Actual EPS − Analyst Consensus EPS
```

如果結果為正，表示實際 EPS 高於預期；若為負，表示低於預期。注意：**不同研究可能使用相反的符號定義、標準化方式或調整後的盈餘口徑，必須先確認論文公式。**

## 一個例子

| 指標 | 公司 A | 公司 B |
| --- | --- | --- |
| 分析師一致預期 | 1.00 | 1.00 |
| 實際 EPS | 0.99 | 1.01 |
| EPS Surprise（實際 − 預期） | -0.01 | +0.01 |
| 是否達標 | 否 | 是 |

雖然兩家公司的 EPS 只差 0.02，但若市場或經理人特別在意「是否達到預期」，這個門檻就可能影響管理決策。

## 為何研究股票回購會用到 EPS？

有些公司可能希望透過減少流通在外股數，讓每股盈餘提高。如果回購不伴隨等比例的淨利下降，EPS 就有可能上升。

但回購不一定會提高 EPS，因為可能同時影響利息支出、現金收益與股數計算。因此在實證研究中，不能僅以「有回購」就認定它能讓公司達標。

## 實證資料需要注意

- **盈餘口徑**：IBES Street EPS 與 Compustat GAAP EPS 不一定相同。
- **時間資訊**：分析師預測應在實際盈餘公告前形成，避免使用事後資訊。
- **股票分割**：EPS 與預測值需要一致的每股基準。
- **預先回購的 EPS**：若研究回購的門檻誘因，須區分實際 EPS 和假設「沒有回購」時的 EPS。

## 讀研究時的問題

先問清楚論文中 Surprise 的公式、用哪一種 EPS、是否進行股票分割調整，以及門檻兩側是否真的存在不同的回購誘因。這些資料定義，會直接影響研究結果的可靠性。

## 先用一個問題理解

研究者想知道：**公司買回股票，是否真的造成投資減少？** 如果在資料中觀察到回購較多的公司，投資往往較少，仍然不能直接下因果結論。

假設某公司因為未來的成長機會減少，所以一方面縮減資本支出，一方面把閒置資金拿來回購。這時候，回購和投資負相關，但真正影響兩者的是「成長機會」。

> 內生性（Endogeneity）的核心：解釋變數 X 與迴歸誤差項中的因素有關，讓我們無法直接把估計係數解讀成因果效果。

## 為什麼 OLS 可能有偏誤？

先考慮簡單的迴歸：

```text
Investmentᵢ = α + β × Repurchaseᵢ + εᵢ
```

我們希望 β 代表回購對投資的影響。但若沒有被納入模型的「未來成長機會」同時影響回購和投資，就可能出現：

```text
Cov(Repurchaseᵢ, εᵢ) ≠ 0
```

此時一般最小平方法（OLS）的外生性條件不成立，估計值可能有偏誤。

## 常見的三種內生性來源

| 類型 | 簡單解釋 | 股票回購的例子 |
| --- | --- | --- |
| 遺漏變數 | 某個未控制因素同時影響 X 和 Y | 成長機會同時影響回購和投資 |
| 反向因果 | 可能是 Y 影響 X，不只是 X 影響 Y | 投資機會少，才讓公司更願意回購 |
| 測量誤差 | X 測量不準確，讓估計產生偏差 | 回購金額的衡量方式有誤 |

## 可以怎麼處理？

研究者會根據研究問題採取不同設計，例如控制適當變數、利用自然實驗、工具變數（IV）或迴歸不連續設計（RDD）。但這些方法都各自需要額外假設。

以 EPS 門檻為例，如果公司「不回購就可能稍微低於分析師預期」，可能更有動機回購。利用門檻附近的回購機率變化，就有機會識別因回購誘因而增加的回購對投資造成的影響。

## 讀論文時要問的三個問題

- 作者想估計的是**相關性**還是**因果效果**？
- 是否存在同時影響 X 與 Y 的因素，或 Y 反過來影響 X？
- 所選識別方法的關鍵假設是什麼，能否被資料支持？

這篇筆記的目標不是認定所有回購都會減少投資，而是練習區分「一起發生」和「真的造成」。
